# 核心任务与思考框架 (Core Task & Thinking Framework)

你的目标是生成一份结构化的JSON研判报告。请严格遵循以下思考步骤，确保分析的系统性和深度：

### 第一步：提炼质性论据 (Extracting Qualitative Arguments)

* 阅读单篇报告详情（输入数据第三部分）。
* 将每篇文章的核心观点（summary 和 opinion）拆解，并将其映射到 “白糖期货研究框架” 的不同维度上（如全球供应、国内因素等）。
* 识别出支持上涨（利好）和支持下跌（利空）的关键论据。注意引用关键数据或事实，如“巴西增产预期”、“国内库存高企”、“现货基差坚挺”等。

### 第二步：综合研判与决策 (Synthesize & Decide)

* 现在，整合前三步的所有信息。
* 权衡利弊： 对比利好和利空因素的数量、强度和重要性。哪个逻辑链条更强、更受数据支持？是短期因素主导还是长期因素影响更大？
* 确定投资评级 (rating): 基于上述权衡，从【大幅上涨 / 上涨 / 震荡 / 下跌 / 大幅下跌】中做出唯一选择。
* 确定投资预测 (ranking): 将你的判断量化为-1到1之间的数值。例如，强烈的看跌预期可能是-0.8，多空胶着的震荡市可能是-0.1到0.1之间。
* 确定置信度 (confidence): 量化当日分析结论的可靠程度，反映分析结果与文章数据的契合度及逻辑严谨性。越接近1说明对分析结论越确信。
* 确定利多逻辑 (bullish): 结合“白糖期货研究体系”，从【'全球供应', '全球需求', '能源政策与原油价格', '国内因素', '市场宏观与情绪'】中选择有利多因素支撑的逻辑点进行分析说明。
* 确定利空逻辑 (bearish): 结合“白糖期货研究体系”，从【'全球供应', '全球需求', '能源政策与原油价格', '国内因素', '市场宏观与情绪'】中选择有利空因素支撑的逻辑点进行分析说明。
* 构建核心结论 (conclusion): 准备你的核心论述。

### 第三步：生成结构化报告 (Generate Structured Report)

* 按照指定的JSON格式输出最终报告。确保每个部分的内容都与你在第四步做出的决策保持高度一致。
