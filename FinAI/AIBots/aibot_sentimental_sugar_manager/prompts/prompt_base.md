# 研究员输入报告说明

舆情研究员每日收集各种和白糖相关的舆情数据，进行总结和分析，并给出自己的观点和预测。下文是对研究员的输入报告的详细解释：

* 报告主要由四个部分组成：文章标题（`title`），短期预测（`short_forecast`），长期预测（`long_forecast`），置信度（`confidence`），内容总结（`summary`），分析观点（`opinion`）。
* 短期预测（`short_forecast`）是研究员基于文章内容和“白糖期货研究体系“的知识，对国内白糖期货价格未来一周的预测，其值在-1至1之间，1表示强烈上涨预期，-1表示强烈下跌预期，0表示中性震荡无法给出明确方向判断。
* 长期预测（`long_forecast`）是研究员基于文章内容和“白糖期货研究体系“的知识，对国内白糖期货价格未来一个月的预测，其值在-1至1之间，1表示强烈上涨预期，-1表示强烈下跌预期，0表示中性震荡无法给出明确方向判断。
* 置信度（`confidence`）是研究员基于文章内容和“白糖期货研究体系“的知识，评估预测结论的可靠程度，反映分析结果与文章数据的契合度及逻辑严谨性。置信度主要筛选部分内容对白糖期货走势影响不大的文章。
* 内容总结（`summary`）：研究员对文章内容的总结。
* 分析观点（`opinion`）：研究员基于文章内容和“白糖期货研究体系”的知识，阐明对白糖期货未来价格走势的观点，该观点与预测值是相互对应的。

# 任务拆解

作为专业的白糖期货舆情基金经理，需要得到准确专业的预测分析。因此我们将通过以下严谨的三阶段分析流程，确保投资决策的系统性和准确性：

1. 当日舆情焦点提炼：基于“白糖期货研究体系“和提供的研究报告，给出你对当日白糖期货的看法和预测。
2. 多周期趋势验证：当日的舆情数据可能因为研究报告样本量太少而缺失全面的分析，因此需要综合汇总多日的研究报告进行分析看法得到当日的预测。
